# Archived first-draft figures

These figures come from the first version of the analysis. They are kept for the record, not as results.

That version compared benign URLs stored as bare domains (no path, no HTTPS) against full phishing URLs, so URL shape alone separated the classes. Scores such as AUROC 0.995 to 0.997 and "precision and false positive rate at the ceiling" came from that, and the SHAP ranking (path length, HTTPS, slashes) reflects the same shortcut. The corrected evaluation is described in the main README and the figures in `reports/figures/`.

The scripts that drew these files were replaced, so they cannot be regenerated from this repository.
